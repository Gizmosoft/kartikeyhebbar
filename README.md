# Portfolio Website

Portfolio website for Kartikey V Hebbar, built with Vite, React, and TypeScript.

Visit: [https://kartikeyhebbar.vercel.app/](https://kartikeyhebbar.vercel.app/)

## Development

```bash
npm install
npm run dev
```

## Content updates

All page content lives in `src/data/*.json`. Edit those files (and add images under `public/images/` when needed) to update the site — no component changes required for typical content edits.
